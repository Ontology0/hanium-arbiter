변화 과정은 **생성형 AI의 근거와 판단을 확인하여 신뢰하고 활용하도록 돕는다**는 공통 문제의식 아래 다음 세 단계로 설명한다.

1. 초기 문화·역사 고증 기획: KG-RAG, 사료 출처 매칭, 위험 표시와 역할별 검수 에이전트의 설계 구상.

3. 현재 에이전트 협업 관제: 결정 대상·위임 범위·책임·사람의 개입 지점을 원문 근거와 연결하는 구현과 공개 체험 웹. 현재 기능과 검증 결과는 현재 코드·실행 기록을 근거로 삼는다.

공통 관심사는 근거 추적, 불확실성 표시와 검토 부담 완화다. 사실의 진위, 지식원의 선택과 행동의 승인권은 서로 다른 판정 문제이며, 세 단계가 같은 알고리즘이나 완성된 통합 제품이라는 뜻은 아니다. 7월 자료는 온톨로지·KG 구현을 명시하지 않으므로 모든 단계에서 같은 온톨로지 기술을 유지했다고 단정하지 않는다. 초기 KG-RAG 및 7월 DPO 모델과 현재 관제의 통합 완료도 주장하지 않는다.

7월 보고서 3쪽의 Telegram·RAG 구현 완료 표현, 7~8쪽의 봇 90%·벡터 검색 50%·모델 60%·통합 30%는 당시 작성자의 자체 진행 기록이다. 7쪽 구성도, 8쪽 Telegram 대화 화면, 9쪽 실험 화면을 현재 코드의 종단간 검증이나 외부 달성 성과로 전용하지 않는다. 비용·응답속도 개선과 논문·포스터 등 목표도 측정 결과·발표 실적으로 옮기지 않는다.

최신 전환 동기는 팀의 직접 판단으로 서술한다. 분야별 전문 판단은 도메인 전문가가 설계·운영하도록 하고, 컴퓨터공학 프로젝트는 개별 LLM 호출 서비스에 머무르기보다 여러 도메인과 에이전트에서 재사용할 **권한·근거·사람 개입의 오픈소스 연결 계층**에 집중한다. 개인 설치에서는 의미 추출에 LLM을 사용하고 공개 체험에서는 저장된 모델 분석을 재생한다. 영문 체험 웹·설치 ZIP 배포와 main 소스 공개를 완료했으며 버전 릴리스와는 구분한다. 상세 자료 대조는 [기획·개발 방향의 변화와 근거](../research/project-evolution.md)를 따른다.

[공개 체험](https://culture-fit-demo-production.up.railway.app/workspace)은 Railway 배포를 완료했다. 합성 대화·과거 모델 분석을 재생하며 서명된 방문자 쿠키별 SQLite를 격리하고 자기 체험만 초기화한다. 새 모델 호출·Slack 수신은 차단하며 외부 작업을 실행하지 않는다. 방문자 쿠키를 소유자 신원·동의 인증으로 설명하지 않는다. 영상은 당시 로컬 전용 DB의 촬영본이므로 현재 라이브 UI와 동일함을 주장하지 않는다. 영문 UI와 [설치 ZIP](https://culture-fit-demo-production.up.railway.app/download)을 제공한다. 기존 시연 예시의 영어 별칭 표시와 승인 식별자 보존을 격리된 재현 UI에서 확인했다. 사용자가 입력한 한국어 원문은 바꾸지 않는다. 배포 구조는 [Railway 문서](../railway-deployment.md)를 따른다.

Title / 제목
Culture-Fit 컬처핏 | Open-source Human-in-the-Loop (HITL) | elevenlabs.io

English
Culture-Fit is an MIT-licensed, open-source Human-in-the-Loop (HITL) coordination layer for developers worldwide building multi-agent workflows. It connects conversational evidence, delegated decision authority, and human input to help agents identify who should decide and when a person is needed.

Reuse it through MCP tools, an A2A analysis service, or a Skill package with instructions and a Python helper. Run these integrations in your own environment; the public demo is a web experience, not an MCP/A2A endpoint. The source is public on the development branch; a versioned package release is still ahead.

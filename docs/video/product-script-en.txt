Two agents can share the same information. But does that mean they have the same authority?

When different people delegate authority, the agents need to know whose approval a decision requires.

Culture-Fit is an open-source Human-in-the-Loop layer. It connects evidence, delegated authority, and human judgment when a decision needs it.

Try it in your browser, or download the source and run it in your own environment.

Download and extract the source ZIP. Use uv to prepare the Python environment.

Choose your operating system in the setup guide. On Mac, use the shell script. On Windows, use the PowerShell command.

If you use OpenClaw, download the Skill ZIP and configure it to connect to your running Culture-Fit server.

The interface is in English. Conversation analysis supports both English and Korean.

In your own installation, agents can use MCP to report conversations and query next actions and authority.

## Recording constraints applied

- The final public deployment was confirmed before recording.
- Capture landing, actual download (source + Skill), macOS/Windows guide, workspace first screen, source-message evidence, partial approval, complete approval, and resulting authority owner.
- The partial-approval result must remain a conflict. The complete-approval result must show Review Agent as owner for payment-release-1.2 / approve.
- No new model calls, live agents, external Slack, or external actions. Operator-entered approvals use only the recording visitor.
- Download/source installation is not an automatic integration. Windows is documented; no physical Windows execution is claimed.
- New filenames: culture-fit-product-ko-1080p.mp4, culture-fit-product-en-1080p.mp4; separate scripts, audio, captions and validation.
- Both narration tracks are newly generated from these scripts and retain 1.0x speed. Three English caption boundaries move by +0.75/+0.40/+0.35 seconds; visuals stay 180 seconds.

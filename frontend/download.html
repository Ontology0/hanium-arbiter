01

Start the local dashboard

Install uv using its official installation guide ↗, then extract the source ZIP. Open a new terminal so uv is available.

In Terminal, change to the extracted project folder containing pyproject.toml. Replace the example path below with your folder.

Terminal
cd "/Users/you/Downloads/culture-fit"
uv --version
./start-macos.sh

Run the start-macos.sh file included in the extracted project. If your archive tool removes its executable permission, run chmod +x start-macos.sh in that folder first.

Choose Extract All for the source ZIP, then open PowerShell in the extracted project folder containing pyproject.toml. Replace the example path below with your folder.

PowerShell
Set-Location 'C:\Users\you\Downloads\culture-fit'
uv --version
powershell -ExecutionPolicy Bypass -File .\start-windows.ps1

This command runs the local start-windows.ps1 file from the extracted project. The Windows launch flow has not been verified on a physical Windows machine.

Keep the terminal running, then open http://127.0.0.1:8787/workspace ↗. The launch script starts the local API and dashboard; it may download project dependencies.

Live model briefings require a configured model provider. Downloading or starting the dashboard does not connect external agents or Slack automatically.

02

Connect an MCP client

Add this stdio configuration to a client that uses mcpServers. Keep the local API running and replace the example with the absolute path to your extracted project.

macOS · example MCP configuration
Loading configuration…

If your client cannot find uv, use the absolute path to the uv executable as command. Client configuration formats vary. The API URL points to your local machine, not the public demo.

After restarting your client, ask it to report a conversation and check the next action. The agent must explicitly call the tools; existing conversations are not collected automatically.

03

Using OpenClaw instead?

Extract the Skill ZIP. Add the folder containing arbiter-coordination to OpenClaw's skills.load.extraDirs, following the included setup notes.

Start the Culture-Fit server first. Ensure OpenClaw can run python3 (Python 3.10 or later); uv managing the server's Python does not guarantee this helper is on OpenClaw's path. The default API URL is http://127.0.0.1:8787.

The Skill reports messages through explicit agent actions. It does not automatically collect conversations, authenticate owners, or connect to the public demo. Follow your installed OpenClaw version's configuration requirements.
